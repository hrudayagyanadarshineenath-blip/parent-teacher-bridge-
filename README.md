# 🌸 Parent Teacher Bridge

### Bridging the Gap Between Parents, Teachers, and Schools

Parent Teacher Bridge is a web-based application developed as a **Minor Project at Ravenshaw University**. The main idea behind this project is to make communication between parents and teachers easier, faster, and more organized.

In many schools, parents do not always receive timely updates about their children's academic performance, attendance, and other important activities. This project aims to reduce that communication gap by providing a common digital platform where parents, teachers, and administrators can stay connected.

The application provides separate dashboards for different users, making it easier to access information and manage student-related activities in one place.

---

## 🎯 Project Objectives

- To improve communication between parents and teachers.
- To provide parents with easy access to their children's academic information.
- To make student attendance and marks management more organized.
- To provide information about useful government schemes.
- To create a simple and user-friendly platform for school-related activities.
- To reduce communication gaps through a centralized digital system.

---

## ✨ Key Features

### 👨‍👩‍👧 Parent Module
- Dedicated parent dashboard.
- View student attendance records.
- Check academic marks and performance.
- Access information about government schemes.
- Voicemail and communication-related facilities.
- Language selection for a more accessible experience.

### 👩‍🏫 Teacher Module
- Dedicated teacher dashboard.
- Manage student-related information.
- Support academic and attendance management.
- Access relevant student records.

### 🛡️ Admin Module
- Dedicated administrator dashboard.
- Manage teachers and parents.
- Manage student information.
- Manage government schemes.
- Access and organize important platform information.

### 🌐 Additional Features
- Simple and user-friendly interface.
- Role-based dashboards.
- Organized navigation and settings.
- Multilingual interface support (English, Hindi, and Odia).

## 🗄️ Database Structure

The project uses MySQL with the database name:

`parent_teacher_bridge`

The database contains tables for managing different types of information:

- **teachers** – Stores teacher details and login information.
- **parents** – Stores parent details and account information.
- **students** – Stores student details and parent relationships.
- **admins** – Stores administrator login information.
- **attendance** – Maintains student attendance records.
- **marks** – Stores academic performance information.
- **schemes** – Stores information about government schemes.

These tables help organize and manage the information required by the application.
